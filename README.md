# novomundo_simulação

Simulação de um indivíduo de modelo neural espelhado no ser humano, **sem defeitos**,
introduzido num mapa 2D regido por calendário lunar.

> O indivíduo busca conhecimento e espelha no externo suas próprias vontades.

## Etapas de desenvolvimento

| # | Etapa | Estado |
|---|---|---|
| 1 | **Entendimento** — discussão, estresse, base de pedra informativa | **em curso** |
| 2 | **Construção livre** — implementação e experimentação dentro da pedra | aguardando |
| 3 | **Implantação final** — consolidação e estabilidade | aguardando |
